### 1.3 关键结构性发现
1. **爱语APP 是最佳样本**：单人开发者 @无机化合物，靠**图文**起家。功能演进路径：自建 API → 表情包导入 → 音色导入 → **降 API 消耗** → 模块系统 / 动态上下文 / **外部访问服务**（把 AI 接进 Minecraft、微信）。他用"开发这个功能差点做死我""谢谢你们一如既往的支持喵"这类语气维护社区。
2. **图文的性价比高于视频**：8.7万、6.1万、6423 赞的高转化内容全是图文。制作成本低、信息密度高、适合放对话截图。
3. **搜索心智已经形成**：抖音"相关搜索"里出现 `人机ai聊天软件推荐`、`ai聊天网页版怎么玩`、`ai聊天网站开发`、`人机恋设定`。这些是**免费流量入口**。
4. **私域形态是"进群拿人设"**：妈咪们产指令卡 → 粉丝求卡 → 导流进群。这是这个圈子天然的 UGC 分发结构，也是二期"卖卡"的现成心智。
5. **成本焦虑是第一痛点**：三条 5万+ 赞内容直接关于"养不起"。**这不是抱怨，是需求**——谁解决它，谁就能被自发传播。

## 2. 账号策略

### 2.1 主阵地：产品官方号（H1 定案）
按用户定案执行。官方号做三件事：
- **更新日志**（每次功能上线一条图文，学爱语的"v2.9.0 更新啦，模块系统·动态上下文·外部访问服务，哪个是你最中意的功能呢"）
- **成本实测**（"同一批对话，优化前 ¥0.054/轮，优化后 ¥0.017/轮"——这类内容在这个圈子是稀缺品，且直接展示产品价值）
- **角色发布**（新角色 + 立绘差分 + 试听）

### 2.2 建议并行：开发者个人号（零边际成本）
数据结论明确：这个品类起量靠人格不靠官方。**建议**同步养个人号，内容就是"我一个人做这个产品"的过程记录。
定位分工：官方号发"有什么"，个人号发"为什么、难在哪、被你们骂了什么"。
> 这是策略建议，不是反对你的定案。若采纳，个人号内容可由官方号转发，互为放大器。

### 2.3 不做的事
- ❌ 不买测评号商单（这个圈子的测评号一旦收钱就会被粉丝质疑，反而污染口碑）
- ❌ 不做"无限制/无违禁词"类卖点内容（既是我的边界，也是账号存活问题——这类号在抖音的封号率极高）
- ❌ 不刷量、不买粉（抖音对 AI 类目的异常互动很敏感，一旦限流整个账号废掉）
- ❌ 不做"预告类"文案（沿用你尚贤圈的对外口径纪律：对外永不写预告）

## 3. 内容生产：图文模板（可直接套）

### 模板 A · 对话截图型（最高 ROI）
```
图1：一句钩子（大字，无背景装饰）—— "我盯着这五个字，愣了好久"
图2-5：真实对话截图（角色侧衬线字体，用户侧无衬线，视觉上就好看）
图6：一句话收尾 + 产品名小字
```
要点：**对话本身是内容，产品只是出处**。截图必须漂亮到"用户想拿去当头像"。这就是 §4 分享图生成器存在的理由。

### 模板 B · 更新日志型
```
图1：版本号 + 三个关键词（学爱语的"模块系统·动态上下文·外部访问服务"）
图2-4：每个功能一张对比图（之前 / 之后）
图5：一句感谢 + 求反馈
```

### 模板 C · 成本实测型（差异化定位）
```
图1：标题"我把和 AI 聊天的成本砍到了 1/3"
图2：账单截图（真实数据）
图3：原理极简图（缓存命中 vs 不命中）
图4：产品里怎么看自己的消耗
```
**这类内容目前抖音没人做**，因为大多数产品自己算不清。这是能占住的心智位。

### 模板 D · 教程型（转化最强，但有风险）
```
"3 分钟，把你自己的人设做成能聊的角色"
```
⚠️ 教程型转化极强（"5分钟搭建AI女友"2.6万赞），但**必须只教我们自己产品内的操作**。教用户接外部 API 会把他们导向竞品，也容易被判"引导站外"。

### 3.1 发布纪律
- 图文 3-6 张为宜，首图 3 秒内看懂
- 标签固定组合：`#人机恋` `#AI聊天` + 1 个产品词 + 1 个题材词。不堆 10 个标签
- 评论区必须回。**这个圈子的用户把"官方会不会理我"当选择标准**（爱语的评论区就是他的产品迭代来源）
- 发布时间：21:00-24:00（深夜是这个品类的主场景）

## 4. 分享图生成器（H4 定案的主增长钩子）

**这是产品内建的传播装置，优先级高于任何投放。**

### 4.1 为什么它是核心
- 抖音上所有 5万+ 赞的内容，本质都是**用户自己截的对话图**
- 用户手动截图的问题：丑、字体不统一、有系统状态栏、暴露真名
- 我们提供一键出漂亮图 → 用户传播质量上升 → 我们获得的是**带品牌的高质量素材**
- 零成本、自传播、不可被竞品的投放压制

### 4.2 功能设计
```
选中若干条消息 → "生成分享图"
  ├─ 版式：信纸 / 极简 / 拍立得 / 长卷（对应皮肤 token，可卖新样式）
  ├─ 字体：角色侧衬线、用户侧无衬线（与产品内一致 → 视觉识别）
  ├─ 脱敏：自动隐藏用户名（可选显示昵称）、去掉时间戳（可选）
  ├─ 水印：右下角极小产品名 + 短链/二维码（可关，但默认开）
  ├─ 尺寸：3:4（抖音图文）、9:16（故事）、1:1、长图
  └─ 导出：PNG，≤ 3MB
```
- 生成走**服务端渲染**（HTML→图片），避免客户端字体不齐；结果存 `share-out` 桶 7 天
- 【必做】分享出去的短链要能带参统计（哪个用户带来的注册）→ 这是唯一可靠的归因手段

### 4.3 传播闭环
```
用户生成分享图 → 发抖音 → 别人扫码/搜短链 → 落地页
  落地页 = 这段对话的"还原版"（只读，角色名 + 前三句可见）
         + "和 TA 聊下去"按钮 → 注册
```
**"点开链接能看到这段对话的开头，但要聊下去得自己来"** —— 这是这个品类最强的转化钩子，因为它卖的不是功能，是**别人和 TA 的故事的好奇心**。

## 5. 站内社区（H3 + K1 定案：广场 + 评论 + 分享流）

### 5.1 三个板块
| 板块 | 内容 | 一期是否做 |
|---|---|---|
| **广场** | 官方角色、热门角色、标签筛选、一键开聊 | ✅ |
| **分享流** | 用户发的分享图 + 对话片段（来自 §4） | ✅ |
| **评论区** | 角色详情页下讨论、求设定、晒截图 | ✅ |

### 5.2 明确不做
- ❌ 不做论坛式发帖/版块/等级体系（维护成本高，且会把产品变成社区而非关系场）
- ❌ 不做私信（用户和用户之间私信是这个品类最大的骚扰源，且我们不做客服）
- ❌ 不做排行榜 PK / 投票活动（会招来刷量）

### 5.3 冷启动
一期不指望 UGC 量。做法：
1. 官方角色详情页下的评论区先由**我们自己写 10-20 条高质量示例**（角色解析、玩法提示、名场面）
2. 广场首屏放"编辑精选"人工运营位（不是算法推荐，一期没有数据量）
3. 从抖音评论区捞活跃用户做首批分享（私信邀请，给 Ultra 体验期）

### 5.4 内容治理（产品功能项）
- 分享内容进广场**默认需审核**（后台队列，管理后台 I8 已定案）
- 举报入口每条必备；举报达阈值自动隐藏（不是删除，人工裁决）
- 敏感词库后台可维护（沿用尚贤圈 `敏感词库扩充` 的做法）
- 用户可见的"为什么被隐藏"提示 + 申诉入口（**申诉走自动复审，不走客服**）

## 6. 创作者激励与卖卡（二期）

### 6.1 心智已经现成
抖音实测：`进群拿人设`、`不要二传二改指令`、"妈咪"这个称呼——说明**"人设卡是有作者的作品"**已经是社区共识。我们不需要教育市场，只需要给一个比 QQ 群更好的分发和变现通道。

### 6.2 一期铺的路（现在就做，成本极低）
- 角色卡有 `author` 字段与署名展示（哪怕一期只有官方角色）
- 角色卡有"来自 XX 的分享"来源标记（导入时保留）
- 角色卡详情页预留"支持作者"位（一期跳爱发电主页，二期变站内分成）
- **禁止二传二改的声明位**（社区会感激这个，成本是一行 UI）

### 6.3 二期机制
```
创作者上传公开卡 → 审核 → 上架
  免费卡：挂"支持作者"（引流到其爱发电主页，平台不碰钱）
  付费卡：创作者定价，平台抽 30%
激励：按"被开聊次数"给创作者平台额度奖励（不是现金，避免结算与合规复杂度）
```
**关键取舍**：一期二期都**不做资金池**。分成走爱发电各自的创作者主页，平台只记账与展示。理由：碰钱就要面对结算、发票、税务、纠纷，一个人做不动，且这是"我不找客服"约束下的必然选择。

## 7. 转化路径与埋点

### 7.1 主路径（北极星：首次对话完成率）
```
抖音图文 → 评论区/主页链接 → 落地页 → 加主屏/直接打开
  → 选一个角色（★不要先注册、不要先要 Key）
  → 直接聊 3 轮（体验额度 ¥3 覆盖）
  → 第 3 轮后引导注册（"想留住 TA 就建个账号"）
  → 引导配 BYOK 或买档位
```
**每一步都要埋点**，且**首次对话完成率必须能按来源拆解**（抖音/搜索/分享图/直接访问）。

### 7.2 埋点清单（最小集）
```
landing_view / role_pick / first_msg_sent / first_reply_done(3轮达成)
signup_start / signup_done / byok_added / byok_verify_ok
pay_wall_view / tier_view / afdian_redirect / entitlement_granted
share_image_created / share_link_click / share_link_signup
push_permission_prompt / push_permission_result / care_msg_opened
credit_exhausted / pack_purchase
```
### 7.3 关键指标与判读
| 指标 | 健康值 | 不健康时先看什么 |
|---|---|---|
| **首次对话完成率**（北极星） | ≥ 55% | BYOK 校验失败率、首字节延迟、角色开场白质量 |
| 注册转化（聊满 3 轮后） | ≥ 30% | 注册引导出现的时机与文案 |
| 次日留存 | ≥ 35% | 记忆是否生效（"它记得我说过什么"） |
| 7 日留存 | ≥ 20% | 主动关怀是否送达 |
| 付费转化 | ≥ 4% | 付费墙出现的时机（**不能早于首次高质量对话**） |
| 分享图生成率 | ≥ 8% | 生成入口的可发现性、出图质量 |
| 单用户日均成本 | 按档位盯 | 携带量是否被拉到上限（分册-模型与计费 §3.2） |

## 8. 竞品对标速查（做决策时回看）

| 产品 | 定位 | 可借鉴 | 不要学 |

| **爱语APP** | BYOK 客户端，独立开发者 | 降 API 消耗、模块系统、外部访问、图文自宣、社区语气 | — |

| **星野** | 平台内置，UGC 卡 | 角色卡生态 | 审核一刀切 |
| **cyboxlife** | 活人感、沉浸 | 对话质感优先 | — |

> **"养得起的人机恋客户端"** —— 竞品在卷角色数量和生成质量，我们卷**成本透明 + 记忆可靠 + 不出戏**。这三条恰好是抖音上点赞最高的三条抱怨。
