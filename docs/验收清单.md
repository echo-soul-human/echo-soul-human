> 标 **【用户必做】** 的条目需要你亲手操作或拍板；其余由开发/CI 完成，你只看结果。

## 附：验收执行建议

1. **不要攒到最后一次验收。** 每个阶段出口判据（任务总清单里每段的"P× 出口"）达成时就验一次，问题越早发现越便宜。

4. 每次发版前必跑的四道 CI 防线：`check-sql` / `check-prefix` / `audit-sw` / 密钥自检。这四条是防止"已经做对的事被后来的改动弄坏"，**永远不许为了赶进度而关掉**。
