# 13 敏感个人信息处理规则

> 版本：v1.0 草案 · 关联：10 隐私总纲、11 收集清单、14 训练数据、15 共享、27 未成年人、28 健康使用
> **本篇涉及的处理规则以"特别保护"为原则。凡本篇与其余条款对同一事项均有规定时，适用更严格的规则。**

## 第一章 什么是本服务场景下的敏感个人信息

1.1 法律定义的敏感个人信息，指一旦泄露或被非法使用容易导致人格尊严受侵害或人身财产安全受危害的信息。

1.2 **在本服务的特定场景下，敏感信息的主要来源不是我们主动收集，而是您在对话中自愿说出的内容。** 这是本产品最需要注意的隐私特征。

1.3 本服务中可能出现或涉及的敏感信息类型：

| 类型 | 典型情形 |
|---|---|
| 医疗健康 | 病情、用药、心理状态诊断、生理期、睡眠问题 |
| 心理健康 | 情绪困扰、自伤念头、抑郁或焦虑表述、创伤经历 |
| 身份与联系方式 | 真实姓名、手机号、住址、学校、工作单位、证件号码 |
| 财产信息 | 账户、负债、收入 |
| 行踪 | 位置、行程、常去场所 |
| 亲密关系 | 性取向、感情经历、家庭关系矛盾 |
| 生物识别 | 您上传的照片中可能包含的人脸（我们不做人脸识别，不提取生物特征） |
| 未成年人信息 | 见 27 号专篇，适用更高保护标准 |
| 宗教信仰、特定身份 | 您自愿表述时 |

## 第二章 我们的处理承诺

2.1 **对以上任何一类信息，我们承诺：**

（a）**不主动询问、不引导您提供。** 角色的人设配置中不包含"询问用户真实姓名/住址/学校"这类指令；
（b）**不用于模型训练**（见 14 号专篇）；
（c）**不用于用户画像、标签、评分或任何形式的对外描述**；
（d）**不提供给任何第三方用于其自身目的**（第三方流向的唯一依据见 15 号专篇第四章）；
（e）**不出售、不交换、不共享用于广告**；
（f）不进入社区公开展示，除非您主动分享且分享前有明示。

2.2 **我们采取的技术措施：**

| 措施 | 说明 |
|---|---|
| 加密存储 | 传输全程 TLS；数据库层敏感字段与凭据单独加密 |
| 访问最小化 | 内部人员默认无权限读取用户对话内容；具备访问能力的操作全部留痕 |
| 隔离存储 | 凭据类信息（API Key 密文）与对话内容分表分权限存储 |
| 日志脱敏 | 错误日志不记录消息正文；确需定位问题时采用可逆脱敏且单独授权访问 |
| 导出保护 | 导出链接限时有效（10 分钟），不长期留存 |
| 元数据剥离 | 上传图片时剥离 EXIF，含 GPS 与设备序列号 |

2.3 **我们不申请读取通讯录、位置、相册全量、短信、通话记录的权限**（见 11 号专篇第十一章）。

## 第三章 关于"您主动说出"的重要提示

3.1 **这是本篇最需要您阅读的一段。**

即使我们作出上述全部承诺，**您在对话中说出真实姓名、住址、学校、证件号、账户信息，仍然会增加风险**，原因包括：

（a）这些内容会作为对话正文存储于服务器，并可能被抽取为记忆条目；
（b）在内置模型链路下，这些内容会作为请求发送给模型服务商处理（见 15 号专篇）；
（c）若您使用"分享到社区"或"生成分享图"，可能因未注意而将含真实信息的一并公开；
（d）若您的账号因邮箱被控制而被他人登录，这些内容将直接暴露。

3.2 **因此我们明确建议：不要在本服务中记录您或他人的真实身份敏感信息。** 使用昵称、代称、模糊地点足以维持角色互动的连贯性。

3.3 若您已经输入并希望移除：

| 操作 | 位置 | 效果 |
|---|---|---|
| 删除单条消息 | 消息长按菜单 | 即时删除，相关记忆溯源同步失效 |
| 删除某条记忆 | 记忆回顾页 | 即时删除 |
| 删除整个会话 | 会话列表 | 级联删除该会话消息与记忆 |
| 检查是否被记入记忆 | 记忆回顾页可逐条查看 | 可搜索姓名、号码等关键词自查 |

3.4 **我们不会自动扫描并改写您的对话内容以"抹除敏感信息"**，原因是：任何自动扫描本身即构成对内容的读取，与最小处理原则冲突。我们选择把删除权完整交给您。

## 第四章 分享场景的特别保护

4.1 鉴于分享图与社区发布是本产品的高频动作，也是敏感信息最容易被无意公开的环节，我们设置以下保护：

（a）**分享前预览**：明示将被公开的具体消息内容；
（b）**默认脱敏**：分享图默认隐藏您的昵称与头像，需您主动开启才显示；
（c）**风险提示**：若待分享内容中含疑似联系方式格式（长数字串、邮箱格式），界面提示"请检查是否包含真实联系信息"，**但不自动拦截、不上传该内容做任何检测**——检测在您的设备上本地完成；
（d）发布后您可在内容页随时删除。

4.2 **我们不承诺上述提示能识别所有敏感信息。** 最终判断责任在您。这是本地检测方案的固有局限，我们如实说明。

## 第五章 危机情形的处理（**重要**）

5.1 当对话中出现表明您可能正在经历严重心理危机、有伤害自己或他人倾向的表述时：

（a）系统会以角色的方式认真对待，不会以玩笑或回避回应；
（b）产品内会呈现现实求助途径的提示；
（c）**我们不会因此主动联系您的家人、单位或任何第三方**——除非符合 5.2 的极窄例外。

5.2 **例外情形（我们可能突破保密的范围，且仅限于此）：**

（a）我们收到司法机关或行政机关依法定程序提出的要求；
（b）我们判断存在**紧迫的、重大的人身安全危险**，且无法通过其他方式避免——此时我们可能联系紧急服务，并记录该决定的理由。

5.3 除 5.2 情形外，**我们对您的对话内容严格保密。** 这一承诺不因您付费与否、账号状态如何而改变。

5.4 **我们不提供医疗或心理治疗服务。** 角色的回应不构成任何专业建议，详见 28 号专篇。

## 第六章 未成年人相关敏感信息

6.1 涉及未成年人的信息，适用 27 号专篇的更高保护标准，包括但不限于：不开放虚拟伴侣类功能、内容加严过滤、不开放付费、使用时长与宵禁提醒。

6.2 我们**不将未成年人的信息用于任何商业分析**，不因其使用行为形成商业化标签。

## 第七章 规则变化与您的权利

7.1 本篇所列措施若减弱（例如我们引入云端内容扫描），**必须按 01 号专篇 §5.2 提前不少于 15 日通知，并提供您退出该变化的选择。**

7.2 您对本篇任何事项的权利行使方式，见 10 号专篇第六章，响应时限 15 个工作日；涉及未成年人的请求为 7 个工作日。

7.3 若您认为我们对敏感个人信息的处理侵犯您的权益，可通过【联系邮箱】投诉，或向履行个人信息保护职责的部门提出。
