# 09 账号注销与数据删除流程

> 版本：v1.0 草案 · 关联：04 服务终止、10–15 隐私、16–19 费用、20 创作者、24 知识产权、31 免责
> 加粗条款涉及您的重要权利，请重点阅读。**本篇约定的注销权不受任何人工审核阻却。**

## 第一章 注销权

1.1 **您可以随时注销账号，无需说明理由，无需人工审核，无需联系客服。**

1.2 注销入口位于设置页。我们**不要求您联系客服即可提交注销**；但为防误操作与账号盗用，我们可能要求身份验证、提供挽留选项或设置合理确认步骤，**具体形式由我们决定**。

1.3 注销前我们会完整告知后果（第三章），并要求您**二次确认**（输入指定确认词）。这是防止误操作，不是设置门槛。

## 第二章 注销流程

2.1 标准流程：

```
设置 → 注销账号
  → 阅读后果说明（本篇第三章）
  → 【推荐】先执行"导出全部数据"（不受档位限制，免费）
  → 输入确认词完成二次确认
  → 账号进入注销冷静期
  → 冷静期届满，数据被删除，注销完成
```

2.2 **冷静期：7 日。** 期间您可通过同一入口撤销注销，账号与数据完全恢复。设置冷静期的目的是防止邮箱被他人控制时被恶意注销——**这是保护，不是拖延。**

2.3 冷静期内：账号不可登录使用；已产生的计费周期不延长；主动消息暂停发送。

2.4 冷静期届满后执行删除。**删除完成后不可恢复，我们也不保留可恢复的副本。**

2.5 特殊情形：若账号处于未完结的争议处理中（例如退款核查、被举报调查），**注销仍可启动，冷静期延长至争议完结**，最长不超过 30 日，并告知您理由与预计时间。**我们不会以"有争议"为由拒绝注销。**

## 第三章 注销的后果

3.1 **立即失效的事项：**

（a）无法再登录，无法再访问任何对话内容、角色、记忆；
（b）未消耗的额度、未到期会员权益、已购皮肤与角色卡的使用权全部终止（退款处理见第四章）；
（c）已配置的 API Key 被删除（**请您同步在服务商侧作废该 Key**，注销不会让服务商侧的 Key 失效）；
（d）推送订阅被清除；
（e）作为创作者的收款与分成安排终止（余额处理见 20 号专篇）。

3.2 **不可逆的事项：数据删除后无法恢复，我们无法应任何人的请求恢复。** 因此我们强烈建议先导出。

3.3 **您不能通过注销来清除他人的权利。** 例如：您导出并保留的角色卡若含第三方素材，注销不改变您对该第三方的责任；他人已合法购买的您的角色卡，其使用权不因您注销而消灭（见 07 号专篇 §6.2）。

## 第四章 费用与权益的结算

4.1 注销时的费用处理：

| 项目 | 处理 |
|---|---|
| 未消耗模型额度 | 按 18 号专篇申请退款；**不因注销而丧失退款权** |
| 会员剩余有效期 | 按 18 号专篇的比例折算规则申请退款 |
| 加量包未消耗部分 | 同上 |
| 已购角色卡 / 皮肤 | 已交付内容，不退款；但您可在注销前继续使用至有效期结束 |
| 创作者未结算分成 | 按 20 号专篇结算，**不因注销而清零**；需您提供有效收款方式 |

4.2 **退款申请应在注销完成前提出**，或在完成后 30 日内通过【联系邮箱】提出（我们会保留该请求所需的最少信息：订单标识、金额、收款路径，处理完毕后删除）。

4.3 冷静期内提出退款申请的，注销自动暂停至退款处理完成。

## 第五章 数据的删除范围

5.1 **下列内容被真实删除（不可恢复）：**

| 数据 | 删除方式 |
|---|---|
| 全部对话消息（含您发送与角色回复） | 行删除 |
| 长期记忆条目（含向量） | 行删除，向量随之清除 |
| 记忆与消息的溯源关系 | 级联删除 |
| 自建角色及其人设、立绘、配置 | 行删除；关联文件删除 |
| 会话与群聊记录 | 级联删除 |
| 上传的头像、立绘、表情包文件 | 存储对象删除 |
| 已配置的 API Key（密文） | 行删除，**非软删除** |
| 皮肤、通知、偏好设置 | 行删除 |
| 社区发布的帖子、评论、分享图 | 删除或匿名化（见 5.3） |
| 设备标识、推送订阅 | 行删除 |
| 年龄声明与身份核验材料 | 行删除 |
| 认证信息（邮箱、登录态） | 从认证系统中删除 |

5.2 **删除的执行时限：** 冷静期届满后 30 日内完成主数据删除（目标 72 小时）；备份副本按第 5.4 条的周期覆盖。

5.3 **社区内容的特殊处理：** 您在广场、评论、分享流发布的内容，注销时删除。**但若该内容已被他人以分享链接等方式合法访问过，我们无法从他人处撤回**，我们仅删除原始条目并使链接失效。

5.4 **备份中的残留：** 我们的数据库存在周期性备份，备份有保留周期（见 15 号专篇）。备份中的残留数据将在**下一备份覆盖周期内自然消除，目标不超过 30 日**。在此期间：备份不用于任何业务查询、不对外提供、仅用于灾难恢复。

## 第六章 依法留存的范围

6.1 **下列信息在注销后仍被保留，且这是法律要求而非我们的选择：**

| 留存项 | 原因 | 期限 | 保护措施 |
|---|---|---|---|
| 交易流水（金额、时间、商品类型、订单标识） | 会计、税务与财务凭证的法定留存要求 | 依法律规定 | **用户标识被替换为不可逆哈希**，无法关联到您或任何自然人 |
| 网络日志 | 法律法规对日志留存的要求 | 依法定最短期限 | 与身份信息分离存储，不用于关联分析 |
| 依法应当留存的内容处置记录 | 监管要求 | 依法定最短期限 | 仅保留必要字段，不保留正文 |

6.2 **留存的匿名化数据不会用于：** 向您推送、画像、训练模型、对外提供、恢复您的身份。

6.3 **我们不会保留注销用户的对话内容用于任何目的。** 这是本篇最重要的承诺，与 14 号专篇（不用于训练）共同构成内容层面的完整保障。

6.4 若法律机关要求我们提供留存信息，我们依法处理并要求其出具合法手续，见 15 号专篇第六章。

## 第七章 与"删除部分数据"的区别

7.1 注销是删除全部数据。若您只想删除部分内容，下列入口提供细粒度删除，**效果即时、无需冷静期**：

| 操作 | 位置 |
|---|---|
| 删除单条消息 | 消息长按菜单（相关记忆的溯源同步失效，见 11 号专篇） |
| 删除整个会话 | 会话列表 |
| 删除某条记忆 | 记忆回顾页 |
| 删除自建角色 | 角色详情页（其关联记忆一并删除） |
| 删除某个 API Key | BYOK 配置页 |
| 退出不喜欢的社区内容 | 内容页"删除我的发布" |

7.2 **细粒度删除与注销使用同一套删除机制**，不存在"注销才真删、单条删除是软删"的情况。

## 第八章 数据导出

8.1 注销前（以及任何时候）您都可导出全量数据，**免费、不受档位限制**。

8.2 导出内容：全部对话（结构化 JSON）；自建角色（含通用角色卡格式，可被其他工具读取）；记忆条目及其溯源；账号设置；交易记录。

8.3 导出链接为限时签名地址，**过期后需重新生成**。导出文件不在我们服务器上长期留存（临时目录 1 日后清理）。

8.4 **我们不设置"导出需付费""导出需人工申请""导出仅给摘要"这类障碍。** 带走您的数据是您的权利，不是我们的服务。
