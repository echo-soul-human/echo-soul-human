# 32 争议解决与法律适用

> 版本：v1.0 草案 · 关联：01 总纲、10 隐私、18 退款、23 版权、25 申诉、30 处置、31 免责
> **本篇说明遇到问题时按什么顺序解决、适用什么法律、去哪里解决。加粗条款涉及您的重要权利。**

## 第一章 解决顺序

1.1 我们建议按下列顺序处理争议，**从成本最低的路径开始**：

```
第 1 步  查阅本篇与各专篇（多数问题在规则里已有答案）
第 2 步  产品内自助路径
         · 未到账 → "我付了但没到账"（17 号专篇 §7）
         · 计费疑问 → 账单页逐条可追溯（19 号专篇 §6）
         · 内容/账号处置 → 申诉入口（25 号专篇 §6、30 号专篇 §5）
         · 退款 → 订单页自助申请（18 号专篇 §4）
         · 数据权利 → 导出/删除/注销入口（09、10 号专篇）
第 3 步  书面联系【联系邮箱】，说明事实、依据条款与您的诉求
第 4 步  协商（我们承诺在响应时限内给出书面结论，见 §2.2）
第 5 步  外部途径：消费者投诉举报渠道 / 行业主管部门 /
         个人信息保护投诉渠道 / 依法提起仲裁或诉讼
```

1.2 **我们不设置"必须先协商才能主张权利"的前置条件。** 您有权依法直接选择任何救济途径。本篇第二章的协商机制是我们对自己的服务要求，不是对您的限制。

1.3 我们**不要求**您为解决争议支付任何费用，**不要求**您委托特定机构或个人代理。

## 第二章 协商机制

2.1 您通过【联系邮箱】提出的争议请求，我们按下列时限响应：

| 请求类型 | 响应时限 |
|---|---|
| 一般咨询与异议 | 15 个工作日 |
| 未成年人相关 | **7 个工作日** |
| 个人信息权利请求 | 15 个工作日（10 号专篇 §6.2） |
| 申诉（内容 / 账号处置） | 10 个工作日（25、30 号专篇） |
| 退款 | 15 个工作日给出结论（18 号专篇 §4.3） |
| 假冒与诈骗举报 | 尽快核查，无固定承诺但会记录 |

2.2 **我们的书面答复会包含：** 事实认定；依据的具体条款（**精确到条号**）；结论；若您不同意的下一步途径与时限。

2.3 **我们不会以"已处理"为由拒绝二次沟通。** 对结论有异议可在 15 日内要求复核，复核由不同路径进行（25 号专篇 §6.1）。

2.4 协商过程中的往来记录我们予以保留，保留期限不少于争议解决后 2 年。

## 第三章 法律适用

| 《数据安全法》 | 数据分类分级、安全保护义务 |
| 《生成式人工智能服务管理暂行办法》 | 生成内容的服务提供者义务、标识、安全评估 |
| 《互联网信息服务深度合成管理规定》 | 合成内容标识、显著提示 |

3.4 若法律发生变化导致本协议某部分需要调整，我们按 01 号专篇 §5.2 与 10 号专篇 §8.2 的通知程序办理。

## 第四章 管辖

4.1 因本协议及其专篇产生的争议，双方应先行协商；协商不成的，**由我们经营主体所在地有管辖权的人民法院管辖**。

4.2 **我们对该条的诚实说明**：约定管辖条款在消费者合同中可能因未合理提示、或加重消费者负担而被认定为无效。**因此：**

（a）我们以**加粗 + 注册时单独确认**的方式提示本条；
（b）**我们不以本条阻止您依法向有管辖权的法院起诉**，亦不以此作为拒绝协商或拒绝履行的理由；
（c）若本条被认定为无效，争议按法律规定的管辖处理，**本协议其余条款不受影响**（§5.2）。

4.3 涉及个人信息权益、未成年人权益的争议，您亦可依法向履行相应职责的部门投诉，**该途径不受本条限制**。

4.4 **我们承诺不提起明显无依据的诉讼以施压用户。** 主张权利前我们会先书面说明依据与计算方式（31 号专篇 §1.4、§5.3）。

## 第五章 可分割性与存续

5.1 **若本协议任何条款被有管辖权的机构认定为无效、违法或不可执行：**

（a）该条款在认定范围内对该用户不发生效力；
（b）**其余条款继续有效**；
（c）我们以合法有效的条款替换之，并按 01 号专篇 §5.2 通知；
（d）**我们不以该无效条款作为任何处理决定的依据**，并在 15 个工作日内提出修正版本（31 号专篇 §7.2）。

5.2 下列条款在协议终止、账号注销后仍然有效：

| 条款 | 存续原因 |
|---|---|
| 09 号专篇（注销与删除） | 数据处理义务需持续履行 |
| 10–15 号专篇（隐私与数据） | 对已收集信息的处理义务 |
| 14 号专篇（不用于训练） | 该承诺不因终止而失效 |
| 18 号专篇（退款） | 注销后 30 日内仍可主张（09 号专篇 §4.2） |
| 23、24 号专篇（知识产权与许可） | 已发生的使用与授权关系需清算 |
| 29 号专篇（标识） | 已分发内容的标识义务 |
| 31 号专篇（责任） | 责任划分需延续 |
| 32 号专篇（本篇） | 争议解决机制本身 |

## 第六章 语言、文本与版本

6.1 **本协议以中文订立并解释。** 如有其他语言译本，以中文本为准（01 号专篇 §2.2）。

6.2 各专篇的**生效版本以产品内"协议与条款"页面展示的当期版本为准**。本仓库 `docs/legal/` 下的文件为编写源，若与产品内版本不一致，以产品内为准（并应尽快修正）。

6.3 我们保留每篇的历史版本，您可通过【联系邮箱】索取特定日期的版本，用于处理该时期发生的争议。

6.4 版本变更须按 01 号专篇 §5.2 的通知程序办理；涉及训练数据用途（14 号专篇 §2.2）、许可范围扩大（24 号专篇 §8.1）、标识减弱（29 号专篇 §6.2）的变更适用更严格程序。
