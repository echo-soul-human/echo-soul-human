# 15 数据存储、跨境与第三方共享

> 版本：v1.0 草案 · 关联：10 隐私总纲、11 收集清单、13 敏感信息、14 训练数据、03 BYOK、05 依赖声明
> **本篇第四章列出您的对话内容会流向哪些第三方。这是本产品最需要坦白的部分。**

## 第一章 存储位置

1.1 您的数据存储在**我们租用的第三方托管数据库与对象存储服务**中（当期服务商见 05 号专篇第四章）。

1.2 **重要说明：我们选择的托管服务，其服务器可能位于境外。** 这一点的实际含义是：

（a）您的数据在物理上可能存储于境外的数据中心，由境外主体运营的基础设施承载；
（b）这会影响访问速度、可用性（网络可达性波动）；
（c）这构成一次向该托管服务商的"委托处理"，其政策与所在法域的规则对其自身行为生效。

1.3 我们的应对：

（a）**选型时优先具备合理安全资质与数据保护承诺的服务商**；
（b）以加密、访问控制、最小权限降低基础设施层面的风险；
（c）**如实告知您这一事实，不声称"数据全部存于境内"**；
（d）若未来出现兼顾可达性与合规的境内替代方案，我们会评估并在变更时通知。

1.4 **我们不承诺数据仅存储于中华人民共和国境内。** 若您对此有特定要求，请审慎评估是否使用本服务。我们认为说清楚比给一个做不到的承诺更有价值。

## 第二章 存储的技术措施

| 层面 | 措施 |
|---|---|
| 传输 | 全链路 TLS 加密 |
| 凭据 | API Key 采用信封加密，主密钥不进入数据库与代码仓库 |
| 年龄与敏感字段 | 与业务数据分离存储，独立访问控制 |
| 访问控制 | 数据库行级权限策略；用户只能读取自己的数据（技术上强制，非仅政策承诺） |
| 内部权限 | 默认无读取用户对话内容的权限；具备该能力的操作全部留痕可审计 |
| 备份 | 周期性备份，加密存放，保留期见 09 号专篇 §5.4；**每季度做一次真实恢复演练** |
| 上传文件 | 服务端重编码，剥离元数据（含 GPS） |
| 日志 | 不记录消息正文；错误定位采用脱敏 |

## 第三章 保留期限

3.1 期限原则：实现目的所需的最短时间 + 法律要求的最短留存。字段级期限见 10 号专篇第五章与 11 号专篇各表。

3.2 **对话内容不设自动过期清除**，保留至您主动删除或注销。理由与您的控制方式见 10 号专篇 §5.2。

3.3 注销后的留存范围（财务凭证匿名化、日志法定期限）见 09 号专篇第六章。

## 第四章 向第三方的提供（**核心章节**）

### 4.1 唯一依据原则

**我们向第三方提供您的信息，仅限本章列举的情形。** 不存在"其他必要情况"这类兜底表述。

### 4.2 因服务运行必需而提供的信息

| 接收方 | 提供什么 | 目的 | 您的控制 |
|---|---|---|---|
| **模型服务商**（内置链路，当期见 05 号专篇） | **对话上下文：您的输入、检索到的记忆片段、角色配置** | 生成回复 | 可改用 BYOK 自选服务商；可关闭记忆 |
| 您自选的模型端点（BYOK 链路） | 同上，另含您的 API Key 用于鉴权 | 生成回复 | 完全由您决定 |
| **语音合成服务商** | 待合成的文本内容、音色标识 | 生成语音 | 不使用语音则不提供 |
| 托管数据库与存储服务 | 全部业务数据（作为基础设施承载方） | 存储与读取 | 见第一章说明 |
| 网页托管与构建服务 | **仅公开页面文件与构建元数据。不含对话数据、不含账号数据** | 分发网页 | — |
| **爱发电** | 订单相关信息、您的账号标识或邮箱（用于归因比对） | 支付与权益发放 | 可不用爱发电登录（改用邮箱注册），但支付仍需经其完成 |
| 邮件发送服务 | 您的邮箱地址、邮件内容 | 验证码与通知 | 必需 |

### 4.3 因法定义务而提供的信息

（a）**司法机关、行政机关依法定程序提出的要求**：我们依法配合，并要求其出具合法手续；
（b）**监管要求的日志与内容处置记录留存**；
（c）**在 13 号专篇 §5.2 的极窄例外下**（紧迫重大人身安全危险），我们可能联系紧急服务。

4.4 **除 4.2、4.3 所列，我们不会向任何第三方提供您的个人信息。** 具体而言我们不会：出售；出租；交换；用于第三方广告；提供给您所在地的雇主、学校或家人（**包括未成年人的监护人，见 27 号专篇的特别约定**）；提供给征信或数据经纪机构。

### 4.5 透明度承诺

4.5.1 若我们收到政府或司法机关关于您数据的要求，**在法律允许的范围内，我们会在合理时间内告知您**，以便您行使救济权利。

4.5.2 若法律禁止我们告知，我们仍会：要求对方出具合法手续；将提供范围限制在手续明确指向的最小范围；记录该次提供的内部审计痕迹。

4.5.3 我们**不主动、定期向任何机关批量提供用户数据**。

### 4.6 委托处理的约定

4.6.1 对 4.2 中的基础设施与服务商，我们要求其：仅按我们的指示处理；采取与其处理内容相称的保护措施；不得为自己目的使用。

4.6.2 **但我们无法替第三方对其自身行为向您作出保证。** 若第三方违反其政策，您的救济对象包括该第三方；我们会协助您获取必要信息，但不对该第三方的行为承担连带责任，除非法律另有规定。

## 第五章 跨境提供的说明

5.1 除第一章所述"数据可能存储于境外基础设施"外，下列情形构成向境外主体的提供：

| 情形 | 接收方 | 说明 |
|---|---|---|
| 内置模型推理 | 模型服务商 | 若该服务商的处理节点在境外，则每次请求构成一次跨境提供 |
| BYOK 链路 | 您自选的端点 | **由您指定，责任路径由您与服务商之间的合同决定**（见 03 号专篇） |
| 语音合成 | 语音服务商 | 以产品内公示为准 |

5.2 我们会：在选型时评估其数据保护水平；公示当期服务商清单（05 号专篇）；在其政策发生不利变化时重新评估并通知您。

5.3 **我们不做"已完全满足跨境传输所有合规要求"这类我们无力保证的声明。** 我们做的是：如实告知流向、审慎选型、给您选择权。

## 第六章 安全事件响应

6.1 **事件定义**：发生或疑似发生您的个人信息被泄露、篡改、丢失、被未授权访问的情形。

6.2 我们的响应流程：

（a）立即启动处置，控制影响范围；
（b）**在确认事件后 72 小时内**，通过产品内公告与（如涉及面较大）电子邮件告知您；
（c）告知内容：事件的性质与发生时间；受影响的信息类型；我们已采取的措施；您可能受到的影响；您可自行采取的保护措施；我们的联系方式；
（d）按法律要求向有关主管部门报告；
（e）事件处置记录留存，供事后核查。

6.3 **我们承诺：不隐瞒、不淡化、不延迟告知。** 若事后发现我们曾隐瞒安全事件，将构成 31 号专篇中我们不得免责的情形。

6.4 您收到事件通知后建议采取的措施：更换邮箱密码；检查并作废可能受影响的 API Key（**在服务商侧操作，注销本服务账号不会让服务商侧的 Key 失效**）；警惕任何冒充官方的联系（见 21 号专篇）。

## 第七章 变更与您的选择

7.1 本章所列的接收方、流向、存储位置若发生**增加或扩大**，须按 01 号专篇 §5.2 提前不少于 15 日通知；涉及对话内容流向新的第三方时，通知期不少于 30 日，并提供您退出的选择。

7.2 若您不接受某一数据流向（例如不希望内容经内置模型服务商处理），您有权：改用 BYOK；停用相关功能；注销账号并导出数据。

7.3 对本篇任何事项的查询、异议与投诉：【联系邮箱】，标题标注"数据处理"。响应时限 15 个工作日。
