## 三、写作约束（这几条我按实写，不写虚的）

1. **不写"一切后果由用户自行承担"这类整体转嫁条款。** 平台对用户生成内容负有法定管理义务，靠格式条款转嫁不掉；写了不但无效，还会在争议时被认定为不公平格式条款而整体不利。所以 03、26、30、31 里的责任划分是**按真实控制力分配**：谁有能力控制，谁承担对应义务。
2. **不写"我们不对任何损失负责"的无限免责。** 这种条款在消费者场景下大概率不被支持。写的是有边界、可执行的责任限制。
3. **凡涉及用户权利的条款，加粗 + 单独确认。** 包括：扣费规则、注销后数据删除范围、内容处理标准、责任限制、争议管辖。
4. **不承诺做不到的事。** 例如不写"绝不泄露"，写"采用 X 措施，事件发生后 Y 小时内告知"。
5. **术语与产品实际行为一致。** 有效期一律写"31 天 / 372 天"，不写"月"、不写"自动续费"（对应 `docs/分册-模型与计费.md` §5.4 的文案纪律）。
