# 21 反诈与交易安全提示

> 版本：v1.0 草案 · 关联：06 账号管理、03 BYOK、16–19 费用、20 创作者、30 处置
> **本篇不是形式性提示。这个圈子里已经真实发生过的骗局，我们逐条写出来。请读完。**

## 第一章 我们永远不会做的事（**最重要**）

1.1 **下列行为我们绝不会实施。任何以我们名义实施这些行为的人，都是假冒。**

| 编号 | 我们绝不会做的事 |
|---|---|
| **N1** | **向您索要您的 API Key**（无论是完整 Key 还是"后几位用于核对"） |
| **N2** | **向您索要邮箱验证码、登录令牌、会话标识** |
| **N3** | **向您索要支付密码、银行卡号、CVV、身份证支付信息** |
| **N4** | **要求您通过微信、QQ、支付宝私下转账付款**（我们的唯一支付通道是爱发电，见 17 号专篇） |
| **N5** | **要求您添加某个私人账号"开通权限""解锁功能""加入白名单"** |
| **N6** | **要求您下载任何安装包、插件、模组、"客户端补丁"** |
| **N7** | **要求您扫描二维码以"领取额度""验证身份"** |
| **N8** | **主动联系您推销会员、角色卡、"内部渠道"** |
| **N9** | **声称能"解除内容限制""提供无违禁词版本"并收费** |
| **N10** | **以"账号异常需要处理"为名要求您提供信息或付款** |
| **N11** | **通过短信、邮件、站内消息附带链接要求您重新输入 Key 或密码** |

1.2 **我们的通知只有四种渠道**：产品内公告与弹窗、产品内站内消息、我们官方邮箱发出的邮件、您已订阅的设备通知。**我们不在 QQ 群、微信群、评论区、私信里处理任何账号或费用事务。**

1.3 我们的官方身份标识：官方邮箱域名为【填写】；官方账号在各平台以产品内"官方渠道"页面列明为准。**除此之外的"官方"都是假冒。**

## 第二章 这个圈子里已知的骗局类型

2.1 我们如实列出在同类产品的社区中反复出现的骗局类型。**列出它们不代表我们无法处理，而是因为这些骗局大多发生在我们的控制范围之外。**

| 类型 | 手法 | 防范 |
|---|---|---|
| **假官方收 Key** | 冒充官方以"排查问题""补发权益"为名索取 API Key | 见 N1。Key 一旦给出，**立即在服务商侧作废** |
| **代充低价会员** | 声称以低于官方价代充，收款后不交付或交付后立即退款套取 | 我们不接受代充；权益只归付款账号（见 07 号专篇 §3.3） |
| **卖卡私聊交易** | 在群内私聊卖角色卡，收款后拉黑 | 只走平台内上架流程（见 20 号专篇） |
| **"人设卡"二传倒卖** | 将他人免费分享的卡包装成付费出售 | 见 23 号专篇；发现可举报 |
| **假冒客户端** | 分发带恶意代码的"安卓客户端""美化插件" | 我们只有产品内公示的下载直链（见 02 号专篇 §4.2） |
| **情感诱导消费** | 以"TA 会消失""不续费就忘记你"施压充值 | **我们的提醒文案不使用这类话术**（见 17 号专篇 §5.2）；遇到即说明是假冒 |
| **钓鱼邮件/短信** | 仿冒通知，附链接要求"验证账号" | 见 N11。不点击，直接核对发件域名 |
| **账号收购** | 高价收购养了很久的账号（含记忆与角色） | 违反 07 号专篇 §2.2，账号会被收回且不予退款 |
| **虚假"内部解封"** | 声称收费可解除账号处置 | 申诉只走产品内通道，且**免费**（见 30 号专篇第五章） |

## 第三章 交易安全的机制保障

3.1 我们的产品设计本身就消除了若干骗局空间，**这些不是承诺，是技术事实**：

| 设计 | 消除了什么风险 |
|---|---|
| **无兑换码** | 不存在"码被偷""码被倒卖""码失效"纠纷 |
| **无账号间权益转赠** | 不存在"转错人""被骗转赠"（见 07 号专篇 §3.3） |
| **无自动续费、无免密代扣** | 不存在"被悄悄扣钱" |
| **平台不碰资金池** | 创作者分成不经我们手，不存在"平台卷款"（见 20 号专篇 §4.3） |
| **支付全权由爱发电处理** | 我们不接触您的支付凭据，被拖库也不会泄漏银行卡信息 |
| **API Key 不下发到设备** | 即使您的设备被他人短暂使用，也拿不到 Key 明文（见 03 号专篇 §4） |
| **账本不可变** | 我们技术上无法改历史账单，双方都能对账 |

3.2 **我们不提供人工客服，因此也不存在"客服向您索要信息"这一攻击面。** 所有事务走产品内自助路径（见 06、09、17、18 号专篇）。

## 第四章 如果您已经受骗

4.1 **按顺序做，速度优先：**

```
第 1 步  若您给过 API Key → 立即到服务商控制台作废该 Key，并重新生成
         （⚠️ 注销本服务账号不会让服务商侧的 Key 失效，必须去服务商侧操作）
第 2 步  若您给过邮箱验证码或邮箱被控制 → 立即修改邮箱密码、启用二次验证
第 3 步  在本服务内"登出全部会话"（设置页），检查已配置 Key 是否被改动
第 4 步  若您私下转账付款 → 联系收款渠道（微信/支付宝）申诉，并保存全部聊天记录
第 5 步  金额较大或涉及身份冒用 → 向公安机关报案
第 6 步  通过【联系邮箱】告知我们（标题"假冒/诈骗"），我们会：
         · 核查该账号是否被冒用，必要时按 30 号专篇纠正
         · 若涉及权益异常发放，核查并恢复
         · 更新本篇的骗局类型清单，帮助其他用户
```

4.2 **关于损失承担，我们如实说明：**

（a）**发生在您与我们之外的行为（私下转账、给假官方 Key、被群内骗买卡），我们不承担赔偿责任**——这些行为不在我们的控制范围内；
（b）但因我们的系统缺陷、或我们未履行本篇第一章的承诺而导致您受损的，我们依 31 号专篇处理；
（c）您受骗后，我们会协助核查与恢复，但不承诺恢复结果，亦不对发生在第三方环节的损失负责。

4.3 我们不会仅因您受骗而处置您的账号。若您的账号被他人控制并用于违规，我们先纠正状态再与您核实。

## 第五章 社区内的识别方法

5.1 您可以在产品内核对以下信息，识别真假：

| 核对项 | 位置 |
|---|---|
| 官方邮箱域名 | 设置页"官方渠道" |
| 官方账号列表 | 设置页"官方渠道" |
| 安卓应用的唯一下载地址 | 官网下载页（**注意域名一致性，仿冒页常有一字母差异**） |
| 当前所有支付商品与价格 | 产品内档位页 + 16 号专篇 |
| 是否存在某项"人工服务" | **不存在。任何声称提供人工解锁/人工补发的都是假冒** |

5.2 **一条简单的判断规则：任何人让您离开产品去做与账号、费用、Key 有关的事，都是假冒。**

## 第六章 举报与协作

6.1 若您发现有人假冒我们实施诈骗，请通过【联系邮箱】（标题"假冒/诈骗"）告知，并尽可能提供：对方账号、聊天截图、收款方式、时间。

6.2 我们收到后会：核查是否涉及我们的系统或被冒用的名义；在产品内与官方账号发布警示（匿名化处理）；配合执法机关调查。

6.3 **我们不会向举报人支付报酬，也不承诺个案反馈处理结果**（涉及第三方调查时我们可能无法说明）。我们承诺的是：收到即核查，核查即记录。

6.4 您在社区中发布的防骗提醒，我们不会以"涉及第三方"为由清除。
