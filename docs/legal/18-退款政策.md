# 18 退款政策

> 版本：v1.0 草案 · 关联：16 定价、17 到账、19 计费、04 服务终止、09 注销、30 处置
> **本篇涉及您的财产权利，请重点阅读。我们提供自助退款路径，不以人工客服作为前提。**

## 第一章 可退款的情形

1.1 **下列情形，您有权申请退款，我们按本篇时限办理：**

| 编号 | 情形 | 退款范围 |
|---|---|---|
| R1 | **权益未成功发放**（付款后按 17 号专篇第七章处理仍无法到账） | **全额** |
| R2 | **产品实际提供的权益与 16 号专篇明示不符** | 全额或差额补偿 |
| R3 | **重复支付**（同一权益被扣两次） | 退还重复部分 |
| R4 | **非您本人实施的支付**（账号被盗、他人误操作，经核查合理） | 全额，并回收已发放权益 |
| R5 | **我们全面终止服务** | 未消耗额度与剩余有效期按比例退款（04 号专篇 §5.1） |
| R6 | **您因减损变更选择停止使用** | 剩余有效期按比例退款（04 号专篇 §1.2） |
| R7 | **未成年人未经监护人同意的充值** | 见第二 章 |
| R8 | **计费错误**（多扣、重复扣、失败仍扣） | 退还差额或全额，见 19 号专篇 §7 |
| R9 | 您在购买后 **7 日内**申请，且**完全未使用**对应权益 | 全额（我们自愿提供的冷静期，可随时调整或取消该安排） |

1.2 **R9 是我们自愿提供的安排，不是法定义务。** 其适用条件、期限与是否继续提供，由我们决定并在产品内公示；调整按 01 号专篇 §5.2 通知。**"完全未使用"指未使用任何内置模型额度、未使用新增能力（语音、皮肤、扩槽位、主动消息）、未下载已购内容。**

1.3 已产生部分消耗的，我们按 R5/R6 的比例方式处理。

## 第二章 未成年人充值的退款

2.1 若监护人对未成年人未经同意的充值提出退款请求，我们按下列方式办理：

（a）核验监护关系与账号归属（**采用最小必要方式，不要求提供与退款无关的信息**）；
（b）核查该账号的使用特征是否与未成年人使用情形相符；
（c）核查通过的，**退款范围以该账号在相应期间内的充值为限**；
（d）已发放的权益被回收；**已产生的对话数据不因此删除**，仍归账号持有人，可按 09 号专篇自行注销删除。

2.2 **我们不对每一起申请作"绝对退款"承诺**，因为核实能力有限。但我们的处理原则是：**在证据大致成立时倾向于支持退款**，并在拒绝时书面说明理由与申诉途径。

2.3 未成年人相关请求的响应时限为 **7 个工作日**（快于一般请求的 15 个工作日）。

## 第三章 不予退款的情形

3.1 **下列情形我们不予退款，且我们在购买前会明示这些限制：**

| 编号 | 情形 | 理由 |
|---|---|---|
| N1 | 会员有效期自然到期 | 服务已在该周期内提供 |
| N2 | 已消耗的模型额度 | 该部分对应已实际发生的第三方成本 |
| N3 | 已解锁的皮肤、表情包等非消耗型商品（超过 R9 的 7 日冷静期后） | 数字内容一经交付无法退回 |
| N4 | 已购买的角色卡（超过冷静期后） | 同 N3；且涉及创作者已获分成 |
| N5 | 因您自身设备、网络、浏览器不兼容导致体验不佳 | 属技术限制，见 02 号专篇 §4.4 |
| N6 | 因第三方服务商限流、故障导致的部分不可用 | 见 04 号专篇 §2.3、§4.1 |
| N7 | 因您违反 30 号专篇被处置 | 见 §3.2 |
| N8 | 单纯"不想要了"且已超过 R9 的 7 日冷静期，或已使用对应权益 | — |

3.2 **关于 N7 的限制**：因违规被终止账号时，**已消耗的额度与已交付的数字内容不退款**；但**未消耗的剩余额度我们仍予退还**（按 04 号专篇 §5.1 的比例方式）。我们不会以处置为名没收您的全部财产——这种条款既不公平也无效。

3.3 若您在处置决定作出前已提出退款申请，两项请求并行处理，**处置不使退款请求失效**。

## 第四章 退款申请方式与时限

4.1 **申请路径（自助，无需客服）：**

```
设置 → 账单与订单 → 选择该笔订单 → "申请退款"
  → 选择情形（R1–R9 对应选项）
  → 提交
  → 产品内查看处理进度与结果
```

4.2 若产品内入口不可用（例如您已注销账号），可通过【联系邮箱】提出，标题标注"退款"。注销后 30 日内提出仍有效（见 09 号专篇 §4.2）。

4.3 **处理时限：**

| 阶段 | 时限 |
|---|---|
| 受理并给出结论 | **15 个工作日内** |
| 结论为同意后，发起退款 | 3 个工作日内 |
| 款项到达您的支付账户 | 取决于支付通道，通常 1–7 个工作日；**我们不承担该环节的延迟责任，但会提供可查询的凭证** |

4.4 **我们不会要求您提供与退款无关的信息**，不会以"需先注销账号""需先删除数据""需联系客服"作为退款前提。

## 第五章 退款的路径与金额

5.1 **原路退回原则**：退款按您的支付通道原路返回（经爱发电）。

5.2 无法原路退回时（例如通道限制、订单过久），我们提供：

（a）以等额平台额度形式发放至您的账号（**这是替代方案，不是默认方案，我们不会用它替代您应得的现金退款**）；
（b）或与爱发电协调其他退回路径。

5.3 **退款金额计算：**

| 类型 | 计算 |
|---|---|
| 全额退款（R1–R4、R9） | 支付金额全额 |
| 按比例退款（R5、R6） | 支付金额 ×（剩余天数 ÷ 该周期总天数）；额度部分按未消耗比例单独计算，两者取较高者 |
| 部分退款（R8） | 多扣或错误部分的差额 |

5.4 **退款不收取任何手续费。** 我们不会以"渠道费""处理费"名义扣减您应得金额。

5.5 退款完成后，对应权益被回收；**您的对话数据与自建角色不因退款而删除**（数据与费用是两件事）。

## 第六章 争议与申诉

6.1 您对退款结论有异议，可在收到结论后 **15 日内**通过同一入口提出申诉，我们由不同处理路径复核，**10 个工作日内**答复。

6.2 申诉被拒后，我们书面说明理由。您可向消费者投诉举报途径提出，或依 32 号专篇解决争议。

6.3 **我们不承诺"申诉必成"，但承诺"申诉必被独立复核"**，且首次处理人不同时参与复核。

## 第七章 我们的承诺与不承诺

| 我们承诺 | 我们不承诺 |
|---|---|
| 提供产品内自助退款入口，不要求联系客服 | 任何情形都全额退款 |
| 15 个工作日内给出结论 | 款项即时到账（通道时间不由我们控制） |
| 未成年人请求 7 个工作日内响应 | 对每一起未成年人申请都无条件退款（核实能力有限） |
| 退款不收手续费 | 以平台额度替代您应得的现金退款 |
| 违规处置仍退未消耗额度 | 已消耗额度可退 |
| 退款不删除您的数据 | 退款后仍保留付费权益 |
