# 05 开源组件与第三方依赖声明

> 版本：v1.0 草案 · 关联：02 服务说明、03 BYOK、15 数据存储与共享
> 本篇清单随实际依赖更新，以产品内"关于 → 开源许可"页面为最终版本。

## 第一章 说明

1.1 本服务使用了第三方开源软件与商业服务。开源组件按其许可证条款分发，**我们不对开源组件本身作出任何保证**，各组件按其许可证"原样"提供。

1.2 若某开源组件的许可证要求向您提供源代码或保留声明，我们已通过产品内页面、仓库链接或随包文件履行该义务。您可随时通过【联系邮箱】索取对应组件的完整源码与许可证文本，我们在 15 个工作日内提供。

1.3 **商业服务（托管、数据库、模型、支付）由各自运营方独立向您提供，其服务条款与隐私政策对您与该服务方之间的关系直接生效。** 本篇列出其官方条款入口，请您自行阅读。

## 第六章 数据流向声明

6.1 为便于您理解，本章明示**您的对话内容会流向哪些第三方**：

| 场景 | 是否流向第三方 | 流向谁 |
|---|---|---|
| 内置模型对话 | **是** | DeepSeek（用于生成回复） |
| BYOK 对话 | **是** | 您配置的端点（用于生成回复） |
| 语音合成 | **是** | 语音服务商（仅待合成文本） |
| 记忆存储与检索 | **否** | 仅存于我们自己的数据库 |
| 账号与支付 | **是** | Supabase、爱发电 |
| 网页托管 | **否** | GitHub Pages 仅分发静态文件，不接触对话数据 |

6.2 **除上表所列，我们不会将您的对话内容提供给任何第三方**，不用于广告、不用于模型训练（见 14 号专篇）、不出售。

6.3 我们要求上述服务商具备与其处理内容相称的安全与合规能力，并尽可能签署数据处理约定。**但我们无法替第三方对其自身行为向您作出保证。**
