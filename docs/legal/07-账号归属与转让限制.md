# 07 账号归属与转让限制

> 版本：v1.0 草案 · 关联：06 账号管理、16 定价规则、19 计费、20 创作者分成、24 知识产权、30 处置
> 加粗条款涉及您的重要权利，请重点阅读。

## 第一章 账号的归属

1.1 **账号的所有权归我们，您在遵守本协议的前提下享有使用权。** 这是互联网服务的通行安排，其含义是：我们保留在违规情形下收回账号的权利（见 30 号专篇），而不是"账号里的内容属于我们"。

1.2 **您账号内的以下内容，权利归属您或相应权利人，不因账号归属而改变：**

| 内容 | 归属 |
|---|---|
| 您发送的对话消息 | 您 |
| 您自建角色的**人设文字、立绘、配置** | 您（第三方素材须为权利人） |
| 您在社区发布的原创内容 | 您 |
| 您作为创作者上传的角色卡 | 您 |
| 角色生成的回复文本 | 见 24 号专篇第三章 |
| 您的 API Key、邮箱、支付信息 | 您 |

1.3 我们仅在 24 号专篇第四章所列的许可范围内接触与使用上述内容。**账号归属条款不扩大该许可范围。**

## 第二章 使用权的性质

2.1 账号使用权具有**人身属性**：它是基于您本人的注册行为与您与我们的合同关系产生的。

2.2 **因此下列行为未经我们书面同意不得实施：**

（a）出售、收购、出租、出借、赠与账号；
（b）以"共享会员""合租""代充""包月拼车"等名义供他人使用；
（c）将账号作为财产进行分割、质押、继承安排（例外见第五章）；
（d）通过批量注册形成账号库并对外提供；
（e）将账号与外部服务绑定后向不特定人开放登录。

2.3 **违反上述约定的后果：** 我们有权按 30 号专篇采取限制措施，包括收回账号、清除异常数据、终止服务。**因此产生的付费权益损失由行为人自行承担，我们不予退款。**

2.4 我们作出前款处理时会：告知理由；提供申诉渠道；对确属被他人冒用的情形予以纠正。**我们不会仅凭"登录 IP 变化"就认定转让行为。**

## 第三章 付费权益随账号不随人

3.1 **您购买的会员、额度、加量包、皮肤、角色卡，均绑定于账号本身。** 账号不能转让，因此这些权益也不能通过转让账号的方式转移给他人。

3.2 例外情形，我们支持**定向转移**：

（a）**创作者账号注销时**，其未结算的分成余额按 20 号专篇处理，不因注销而清零；
（b）**您误充值到错误账号**：在消耗前提出，我们核查后可将等额权益转移至您的正确账号；
（c）**司法裁判或行政机关要求**；
（d）**账号被我们误处置后的恢复**，同时恢复全部权益。

3.3 除上述情形，**我们不提供账号间权益转赠功能**。理由：一旦开放转赠，账号买卖会借道转赠实现，第 2.2 条将形同虚设，且会显著增加诈骗纠纷（见 21 号专篇）。

3.4 **您为家人朋友代付的情形是允许的**：由您用自己的账号付款、把权益留在自己账号，或由对方用其账号、您代为支付订单。**判断标准是账号是否由使用人本人控制。**

## 第四章 多账号与家庭使用

4.1 一个自然人可以拥有多个账号，**但不得以下列方式使用**：

（a）重复领取新账号体验额度；
（b）规避内容处置或账号限制；
（c）规避限频、并发或反滥用机制；
（d）批量注册用于转售、刷量或对外提供服务。

4.2 **家庭共用一台设备是允许的**（例如同一台平板上多个账号分别登录）。但**同一账号供多人使用不符合第 2.2 条**，因为角色会记住"您"说过的话——多人共用会破坏记忆的准确性，也会让内容处置的责任无法归属。

4.3 我们识别多账号关联的依据包括：邮箱域名批量特征、设备标识、网络地址、行为模式。**关联本身不构成违规，仅在有第 4.1 条情形时处理。**

## 第五章 账号的继承与身后事项

5.1 本服务内的对话具有高度私密性。**因此默认规则是：账号不因持有人死亡而自动转移，我们不向任何人披露账号内容。**

5.2 若您是逝者的近亲属或继承人，并提出下列请求，我们可在核验身份与关系后办理：

| 请求 | 处理方式 |
|---|---|
| 停止计费、注销账号 | **可办理**，无需提供内容访问 |
| 导出对话数据 | **原则上不予办理**；仅在依法必须或我们有充分依据认定不违反逝者意愿时个案处理，我们保留拒绝的权利 |
| 接管账号继续使用 | **不予办理**，与第 2.2 条一致 |
| 恢复已注销账号 | 不予办理（数据已删除，技术上亦无法恢复，见 09 号专篇） |

5.3 **逝者生前通过导出或其他方式自行处置过的数据，我们不介入。**

## 第六章 创作者账号的特别约定

6.1 若您作为创作者上架角色卡，您额外承诺：

（a）对该角色卡内容拥有完整权利或已获得充分授权；
（b）以**您本人控制的账号**收款，不使用他人账号代收；
（c）分成结算信息（含爱发电主页）真实有效；
（d）不通过多账号自购、互刷等方式套取分成（处理方式见 20 号专篇第 6 章）。

6.2 创作者账号停止运营时，**已购买该角色卡的用户权益不受影响**：已购用户可继续在其账号内使用。创作者本人可下架该卡不再对新用户销售，但不得"召回"已售出的卡。

6.3 **这条承诺的意义**：购买者付了钱，不应因创作者停止维护而失去已购内容。这是我们作为平台的担保责任。

## 第七章 与其他条款的关系

7.1 本篇与 24 号专篇（知识产权）共同界定"什么属于您"。若两处表述不一致，**以对您的权利更有利的解释为准**。

7.2 本篇第 2 条的限制不适用于企业或机构用户的另行约定（我们目前不提供机构账户；若开放，将单独订立条款）。

7.3 您对账号归属或转让限制有异议，可通过【联系邮箱】提出；涉及个案特殊情形（例如您因账号被误判为转让而受损），按 30 号专篇申诉程序处理。
