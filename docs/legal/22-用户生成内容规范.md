# 22 用户生成内容（UGC）规范

> 版本：v1.0 草案 · 关联：23 著作权、24 知识产权、25 审核申诉、26 内容安全、27 未成年人、30 处置
> **本篇规定您在社区可以发布什么。您与角色的私聊内容不受本篇约束（见 §1.3）。**

## 第一章 适用范围（先划清边界）

1.1 本篇适用于您在**社区**发布的内容，包括三个板块：

| 板块 | 内容 |
|---|---|
| **广场** | 您公开的角色、角色介绍 |
| **评论** | 角色详情页下的讨论 |
| **分享流** | 您用"分享图生成器"产出的对话片段 |

1.2 **本篇不适用于您与角色之间的一对一私聊内容。** 那些内容按 10–15 号专篇作为个人信息处理，不作为 UGC 管理。

1.3 **这条区分至关重要，请理解它的含义：**

（a）您在私聊里说什么，我们不作为社区违规处理；
（b）但**私聊内容仍受法律约束**，且可能触发 13 号专篇 §5 的危机处置、或 26 号专篇 §5 的法定义务；
（c）一旦您**主动把私聊内容分享到社区**，该部分内容即进入本篇管辖范围。

1.4 您在私聊中的表达自由高于在社区中的表达自由，这是我们的设计选择：**产品不假设用户的内容需要为"公众可见"而准备。**

## 第二章 发布前的确认

2.1 每次发布前，界面会明示：

（a）将被公开的**具体内容**（哪几条消息、哪张图片）；
（b）可见范围（仅自己 / 知道链接的人 / 公开）；
（c）将随内容显示的署名信息（昵称、头像）；
（d）**默认脱敏**：分享图默认隐藏您的昵称与头像。

2.2 **我们不做"默认公开"。** 您需要主动选择公开。

2.3 若待分享内容中含疑似联系方式格式，界面会提示检查（**本地检测，不上传、不拦截**，见 13 号专篇 §4）。

2.4 **您发布即表示您确认：** 您对该内容拥有权利或已获授权；内容不含您不愿公开的真实身份信息；您接受该内容按本篇管理。

## 第三章 禁止发布的内容

3.1 **绝对禁止（法律层面）：**

（a）违反宪法确定的基本原则，危害国家安全、统一、主权的内容；
（b）煽动分裂、破坏民族团结、宣扬恐怖主义、极端主义的内容；
（c）煽动民族、种族、性别、地域、职业歧视，侵害他人合法权益的内容；
（d）淫秽、色情以外的**违法**内容：暴力恐怖、赌博、毒品、诈骗方法、犯罪教唆；
（e）侮辱、诽谤他人，侵害他人名誉权、肖像权、隐私权、个人信息权益的内容；
（f）假冒他人身份、冒用他人名义发布的内容；
（g）侵害他人知识产权的内容（详见 23、24 号专篇）；
（h）虚假信息、谣言，扰乱经济与社会秩序的内容；
（i）法律法规禁止的其他内容。

3.2 **针对本产品的特别禁止：**

（a）**涉及未成年人的性化、软色情、诱导性内容**（零容忍，立即下架并处置账号，必要时依法报告）；
（b）**美化、教唆自伤、自杀、饮食失调等自我伤害行为的内容**；
（c）**以真实在世人物为原型的角色卡**，未经本人授权（详见 §3.3）；
（d）在角色卡或分享内容中嵌入外部联系方式、收款方式、导流链接；
（e）用于批量注册、刷量、套取分成、规避处置的内容。

3.3 **关于真实人物**：以真实在世人物为原型制作角色卡，须获得本人授权。**已故公众人物、历史人物不在此限**，但不得虚构其不当行为并作为事实传播。

3.4 关于露骨性内容：**社区不开放露骨性内容的发布。** 详见 26 号专篇第三章，其中包含我们对这一规则的完整说明与理由。

## 第四章 各板块的具体规则

### 4.1 广场（角色公开）

| 要求 | 说明 |
|---|---|
| 内容完整 | 角色名、简介、开场白不得为空或无意义 |
| 不含第三方 IP | 见 23 号专篇 §3 |
| 不含联系方式 | 除产品提供的官方"支持作者"位 |
| 标签准确 | 不得滥用热门标签获取曝光 |
| 一个角色一条发布 | 不得用近似重复内容占位 |

### 4.2 评论

| 禁止 | 说明 |
|---|---|
| 人身攻击、辱骂 | 针对内容可以不同意，针对人不可以 |
| 刷屏、无意义重复 | 含连续多次相同内容 |
| 引战、挂人 | 公开指名道姓攻击其他用户 |
| 教唆规避限制 | 传授绕过内容处理的方法 |
| 冒名 | 伪装成官方或其他用户 |

### 4.3 分享流

| 禁止 | 说明 |
|---|---|
| 分享含他人真实个人信息的内容 | 包括您与他人的聊天截图 |
| 伪造对话 | 用工具生成虚假对话冒充真实互动 |
| 去除来源署名后传播他人角色卡内容 | 见 23 号专篇 |

## 第五章 版权与授权（要点，详见 23、24 号专篇）

5.1 您发布内容即授予我们**为提供、维护、改进本服务所必需的非独占许可**（存储、展示、传输、格式转换、生成缩略图）。

5.2 **该许可不包含：将您的内容用于模型训练**（14 号专篇）；**对外授权第三方使用**；**用于广告**。

5.3 您删除内容，我们的许可随之终止，**但已合法被他人通过分享链接查看的内容无法从他人处撤回**（见 09 号专篇 §5.3）。

## 第六章 处置与救济

6.1 违反本篇的内容，我们按 25 号专篇（审核与申诉）与 30 号专篇（分级处置）处理。

6.2 **处置原则：内容优先于账号。** 单条内容违规通常只处理该条内容；只有重复、恶意或涉绝对禁止事项时才升级至账号层面。

6.3 您有权：查看被处理内容的具体理由；提出申诉；申诉由不同路径复核。

6.4 **我们不承诺所有内容都能被事前发现。** 我们的治理方式是"规则明示 + 事前审核（角色卡）+ 事后举报 + 阈值自动隐藏 + 申诉"，不宣称做到零遗漏。
